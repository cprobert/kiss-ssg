## What the arms changed on the branch

- **The whole-site alarm.** The old "AI scraping" arm's `CCBot`/`meta-externalagent`/`Bytespider` blocks triggered "no crawler will index it" on every build, after a first fix had exempted only four training tokens. The alarm now fires for `*` or a search engine's own crawler, and lists every other blocked agent in `report().robots.blocked` (`ebd2f4e`).
- **`LocalBusiness` needs an address** (clean room).
- **Allow-all stated as the default** in `kiss-seo`, after the operator asked how a disallow rule reached the code base: none did; the default is `User-agent: *` / `Allow: /`, every real site allows all crawlers, and the live `robots.txt` of all four sites was fetched to confirm it (Netlify, GitHub Pages, no CDN in front).

## The test bed's limit

All three fleet sites were already in good shape for search, after earlier branches' work, so an arm without the skill had little to get wrong. The operator's point on keeping the two additions: these sites are not the best test bench, and the rest of the fleet is in an unknown state. A weaker site — no titles of its own, a blanket AI block, FAQ markup, town pages already published — is the bench that would show what the skill prevents. The clean room is the nearest thing here, and it is one run.

## Not measured

- **A2, town pages:** the only pair was confounded by the site's own notes. A site without that note is the next test.
- **The character-count habit** survives in the old courses arm ("138–156 characters"); the new arm did not cite a count. One run each.
- **A5, dates:** no brief edits content and then rebuilds, so no arm could move a date wrongly.
