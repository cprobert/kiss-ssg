# kiss-ssg v2 engine review — 2026-09-05

This review covers `lib/` and `scripts/` on `main` at commit `1766775`. Five lanes (A–E) each took a slice of the engine — A: lifecycle & promises, B: watch & replay, C: paths & filesystem safety, D: helpers/config/public contract, E: gate tooling — worked by four Opus reviewers plus the orchestrator (Fable) itself for lane E. Verification was adversarial, not a rubber stamp: every P1/P2 claim was reproduced by the orchestrator from the reviewing agent's own repro script before being confirmed, with each claim's disposition (CONFIRMED / PLAUSIBLE-UNVERIFIED / REJECTED) and evidence recorded in a verdict ledger (`scratchpad/verdicts.md`), which is authoritative over the individual lane reports wherever the two differ. Nothing in the engine (`lib/`, `scripts/`, tests, or docs) was changed by this review — all repro scripts ran against a read-only checkout and wrote only into the scratchpad.

Totals, counted from the tables below: **P1: 3** (A-01, B3, D-01). **P2: 21** (17 engine, 4 gate tooling). **P3: 18**. Rejected with evidence: 13 hypotheses. Every P1 and P2 has a repro Fable ran, except the pure-documentation items (A-06, D-08, D-09, D-10, D-11) which are confirmed by grep. (The ledger's own `## Totals` line, reproduced in the appendix, was written before lane E was added and reads "P2: 17"; the tables are authoritative.)

## How to triage this report

- The `Triage` column is left empty for the operator to fill in: fix now / fix later / accept / reject.
- Severities: **P1** breaks consumers (a build silently fails or a process crashes on a documented/intended usage pattern); **P2** is wrong under real usage (silent bad output, a crash reachable only from a template or an edge-case config); **P3** is hygiene (dead code, doc drift, cosmetic output).
- The four watch-mode findings (B1, B2, B3, B6) are consumed by the design spec at `planning/specs/2026-09-05-watch-dependency-graph-design.md`, whose recommendation is to land them first, as their own change, before any watch-mode optimisation.
- Every row's `Evidence` cell either names a repro script under its lane's scratchpad folder (`scratchpad/lane-<X>/…`) or an existing test file, or says "reasoning only" — no finding below is asserted without one of those two.

## Cross-lane themes

- **Silent success — a build resolves/exits 0 with output missing or wrong.** B3 (deleted/missing view compiles to its own filename), A-02/A-03/A-04 (queued-but-never-rendered pages, callback throws), C5 (garbage output directory from an inline template), C6 (non-ASCII fan-out pages dropped), A-07 (glob-metacharacter project paths build empty), E1/E4 (the format gate reports a pass when it checked nothing). This is the single largest cluster and the one the ledger calls out explicitly: several of these are "exactly the case `generate()`'s rethrow was added to prevent."
- **Folder strings never normalised — a trailing slash breaks path arithmetic.** C3 (`assets.js`'s unanchored string replace) and C4 (`model-resolver.js`'s `slice(root.length + 1)`) are the same root cause in two modules; both proposed fixes converge on normalising `config.folders.*` once in `resolveFolders`.
- **Aliasing / shared state across replays and pages.** A-05 (`options.config = this.config` aliases the master config across pages and the sitemap) and B4 (`_registrations`' shallow copy lets a controller's in-place mutation of `options.model` accumulate on every watch rebuild) are the same family at two levels — live-build aliasing vs. replay-to-replay aliasing.
- **Shipped docs (llms.txt/README) lag AIKB or the code.** A-06 (undocumented asset-copy entry in the `data` array), B4 (controller-purity contract lives only in AIKB), D-08 (`folders.src` re-derivation overstated), D-09 (four of six helpers undocumented), D-10 (README config block missing keys), D-11 (three public methods undocumented) — the consumer-facing surface (llms.txt + README) is consistently behind the engine-internal AIKB docs.
- **Helpers degrade by throwing instead of rendering nothing.** D-04 (`markdown` throws on `null`/object/array), D-05 (`isActive` throws on an undefined `href` or missing page context), C7 (`sass` mangles an absolute path and throws) — all three take the whole page out of the build for a template-authoring mistake that a helper should instead log and degrade past.
- **Gates that pass without checking.** E1 (empty diff → pass), E4 (`git diff` failure → pass), E6 (a silent, unvalidated base-branch override that can feed E4), E7 (files prettier can't parse are skipped — this one is the accepted, correct baseline the other three should be judged against).
