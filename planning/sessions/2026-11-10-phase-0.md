**Planned, with an emergent close.** Fable's roadmap and seventeen one-page work orders were the destination and most of the route, written the day before. ## Feedback — recommendations for next session

- **Claude — make the worktree yourself, from the branch, with a name Windows allows.** `isolation: worktree` cuts from `main` and deletes an unchanged worktree, and `aux` (like `con`, `nul`, `prn`, `com1`) cannot be a folder or a ref on Windows. `git worktree add -b wo/<n> .claude/worktrees/<n> <branch>` plus a `node_modules` junction worked for every later batch; brief agents to start every command with `cd <worktree> &&`.
- **Claude — after `git apply --index`, check `git status` before committing.** "Falling back to direct application" means a file reached the working tree but not the index; `008e6a6` shipped without its `GUIDE.md` half for that reason. A commit message claims only what the commit holds: that same message cited an Upgrading note that did not exist yet.
- **Operator — read the one diff the review rule puts in front of you, or say why not.** The alias allow-list was the change with the most reach and the only one no human read. If a phone is the only screen, ask for it as a file (as `CLAUDE.md` was sent); "not read" with no reason is what the rule exists to prevent.
- **Both — settle "Codex or not" at the open, against the branch's surface, and expect to keep it.** The branch decided "no Codex" at the widening and reversed it at the close; the reversal was right (two real defects), and it would have been cheaper as a mid-branch review of the first engine slice than as a close-time round followed by a fix and a second pass.
- **Process — the work-order format works; the README's "one branch each" did not survive the operator's preference.** Seventeen briefs ran on one branch with every Stop and ask honoured and every guess reported; the Sonnet implementers never decided a stop condition for the operator. Keep the format for Phase 1; write the next set expecting one branch, so shared files (`CLAUDE.md`, `TODO.md`, `GUIDE.md`) are named as shared up front rather than discovered as merge conflicts.
- **Process — the scope check earned its place on its first day.** It listed exactly the files each decision added (batch 2's eight, the review fixes' twelve, the bump's five), and every widening went into an Amendment. Keep it in the pulse and the close.
