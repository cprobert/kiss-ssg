# Session — 2026-09-30: The docs site, rebuilt on kiss and deployed to Pages

## Intent (captured at /branch-open)

**Objective:** Rebuild the kiss-ssg docs site as a kiss-built, multi-page site deployed to GitHub Pages under `/kiss-ssg/`, with a design of its own and guide content that cannot drift from `GUIDE.md`.

**Success criteria:**

- [ ] **Builds clean** — `node docs` exits 0 with 0 broken internal links and 0 audit findings, and `npm run gates` passes.
- [ ] **Deploys and works** — after merge, `.github/workflows/static.yml` deploys, and https://cprobert.github.io/kiss-ssg/ loads styled, with every nav link and guide page working under the `/kiss-ssg/` prefix.
- [ ] **Operator eyeball** — the operator looks at the home page and one guide page, on desktop and on a phone width, in the dev preview (`node docs --dev`). This is the visual check: Claude's own screenshots of scrolled pages timed out in the browser tool this session, so Claude has not seen the pages below the fold.

**Non-goals / out of scope:** the `starter/` site that `init` copies (a bigger decision, deliberately left alone); any `lib/` change, including the `{{markdown}}` helper trimming indentation inside fenced code, which the guide controller works around rather than fixes; custom domains.

**Impact surface:** tooling & docs — the docs site under `src/`, `docs.js`, the built `docs/`, and one `CLAUDE.md` sentence. No `lib/`, `bin/` or shipped-file change.

**Expected shape:** emergent — it began as "make GitHub Pages serve the kiss site", grew into fixing the nav and adding an agent-first section, and then into a full redesign and page split at the operator's request.

**Delegation convention:** none: one session.

**Opened late.** The branch was opened after the work was done, on the operator's call ("we should have run a branch open and branch close on this"). The work sat uncommitted on `main` and was carried onto this branch, so this intent is written from the finished work rather than ahead of it. The Pages workflow itself (`static.yml`) was already committed on `main` as `ab02aa5` before the branch existed.

- **2026-09-30 — the review skill gains an external-links rule, and is run on the docs site.** Operator's call: "one of the things that I think is best practise is for external links to open in new windows". `kiss-site-review` (shipped in the `kiss-ssg` plugin, unpublished since 2.6.4) gets a step: list every external link in the built HTML without `target="_blank"`, and fix it in the template with `rel="noopener noreferrer"` and an "(opens in a new tab)" cue for screen readers. A `test/unit/skill-coverage.test.js` row pins it, seen red against the skill before the edit. This touches a shipped skill, so the impact surface is no longer purely the docs site; still no `lib/` change. Then the skill is run on this branch's docs site.
- **2026-09-30 — an engine fix: the dev server's endless rebuild.** Found while re-checking a review fix: `node docs --dev` rebuilt forever. `node docs` reports `process.argv[1]` without the `.js`, and the watcher watched that path, which is also the `docs/` build folder, so every page written triggered another replay. This is also why every screenshot of a scrolled page timed out earlier in the session: live reload never stopped. Operator's call: fix the engine on this branch rather than work around it. `lib/watcher.js` now resolves the entry to a file the way Node does and never watches a folder. Two regression tests were seen red first, `AIKB/watcher.md` and `types/watcher.d.ts` updated. **The impact surface gains engine internals** (still a patch, no public API change), and this non-goal is withdrawn: "any `lib/` change". The close's Codex review now applies.
