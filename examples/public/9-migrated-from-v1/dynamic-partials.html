When the partial name is undefined

A dynamic partial takes its name from the model: {{> (lookup this 'partial')}}. When the key is missing from one record out of many, v1 rendered an empty string and carried on. v2 fails the page — so guard the call, and let the warning tell you which key went missing.

Why this one bites

In a real migration this was 40 pages of one site failing with The partial undefined could not be found — a message naming neither the key nor the page. The same 40 pages had been shipping without that block under v1, green, for a year. v2 is right to fail, and the warning is there so the diagnosis takes a second rather than an afternoon.

How this example works

Two blocks above name a partial and render it — one .hbs, one .md. The third is the guarded case. Guard with the plain property ({{#if partial}}) when a missing block is acceptable, and let the page fail when it is not: a missing block on a live page is a decision, not an accident.
