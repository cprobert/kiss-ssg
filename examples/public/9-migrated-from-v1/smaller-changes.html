The smaller changes

None of these take more than a line, but all of them are in this script, so you can see the v2 form rather than infer it.

Node 22.12 first

engines.node is >=22.12.0. Check it before touching any code: v2 will not install or run below it, and a pinned dev version in .nvmrc has to move too.

ESM, and CJS still works

import Kiss from 'kiss-ssg' is the form. require('kiss-ssg') still resolves on Node 22.12 and up, so a CommonJS build script does not have to be rewritten to migrate.

utils is a named export

import Kiss, { utils } from 'kiss-ssg', not a deep path into libs/. This script uses utils.toSlug for the deduplication on the output paths page.

Controllers export default

controllers/shelf-item.js is an ES module with a default export. module.exports = is still accepted, so controllers can be migrated one at a time.

The generate callback fires last

In v1 it ran before the files were written. In v2 it runs after, so a callback can read its own output — this build's console line index.html on disk when the callback ran: true is that check.

What did not change

The per-page generate: false option, ext, copyAssets(), viewStats(), getModelByID(), and callback.call(this, …) binding the instance. Underscored fields such as _stack are internal and unversioned — use .sitemap() to enumerate pages.

How this example works

The migration guide these pages follow ships with the package as node_modules/kiss-ssg/llms.txt, § Migrating from v1. Read it first; use this site to see each recipe as running code.
