# Microcopy patterns

These apply the evidence; they are not fixed formulas. Adapt the nouns to the product's own terms. Limits, consequences and recovery routes in the examples (file sizes, "can't undo", who to ask) are illustrations: confirm how the real system behaves before you use them.

| Situation              | Prefer                                                                             | Avoid                                                    | Why                                             |
| ---------------------- | ---------------------------------------------------------------------------------- | -------------------------------------------------------- | ----------------------------------------------- |
| Save action            | Save changes                                                                       | Submit                                                   | Names the resulting action                      |
| Destructive action     | Delete post                                                                        | OK                                                       | States the consequence; "OK" makes people infer |
| Start a known task     | Book a visit                                                                       | Get started                                              | Specific action has stronger information scent  |
| Navigation             | Prices and call-out times                                                          | Learn more                                               | Stands alone and names the destination          |
| Multi-step form        | Continue to payment                                                                | Next                                                     | Says what follows                               |
| Required field missing | Enter your postcode                                                                | This field is required                                   | Ties the fix to the labelled thing              |
| Wrong format           | Enter a date as 31 10 2026                                                         | Invalid format                                           | States the fix                                  |
| File too large         | The file is larger than [limit]. Choose a smaller file.                            | Upload error 413                                         | Plain diagnosis plus the fix for that cause     |
| Upload interrupted     | The upload stopped before it finished. Try again.                                  | Error: upload failed                                     | Retry is offered only where a retry can work    |
| Successful save        | Changes saved                                                                      | Changes saved successfully                               | "Successfully" is redundant                     |
| Empty list             | No posts tagged "events" yet. See all posts.                                       | No data                                                  | Explains the state and the next action          |
| Zero search results    | No posts match "boiler". Try another word, or see all posts.                       | 0 results                                                | Helps recovery, not just reports                |
| Tooltip                | Prices include VAT.                                                                | A three-paragraph explanation                            | Tooltips hold brief extra information only      |
| Permission failure     | You do not have permission to edit this page. Ask a site administrator for access. | Forbidden                                                | Plain words plus a route                        |
| Product spec           | Weight: 1.4 kg                                                                     | Lightweight construction                                 | A number supports comparison                    |
| Status email subject   | Your booking is confirmed                                                          | Important update                                         | The subject is the message                      |
| Action email subject   | Action needed: pay £120 by 14 November                                             | Reminder                                                 | Action and deadline first                       |
| Push notification      | Delivery moved to 14:30–15:30. Track your order.                                   | We have an important update regarding your recent order… | Short, timely, front-loaded                     |
| Download link          | Download the annual report (PDF, 2 MB)                                             | Click here                                               | Destination and format out of context           |
| Confirmation dialog    | Delete 3 files? You can't undo this. [Delete files] [Cancel]                       | Are you sure? [OK] [Cancel]                              | Names what will happen and the risk             |

## Patterns behind the pairs

- **Verb + object** for commands: Save changes, Invite user, Export CSV.
- **Destination noun** for navigation links: Opening hours, Prices and services.
- **Problem + fix** for errors, in the user's words, with no blame. A code is never the whole message; if support needs a reference, put it after the plain explanation ("…Try again. If it keeps happening, contact support and quote reference AB12.").
- **State + reason + next step** for empty states.
- **Outcome, then action, deadline, consequence** for messages.
- **Distinguishing word first** in any short text that people scan in a list.
